Magic Events & Decorators - Customer App PWA

Files:
- index.html: customer-facing app
- manifest.json: installable web app metadata
- sw.js: offline caching service worker
- icon.svg: app icon

Important:
This is a progressive web app package, not a signed Android APK.
To install as a Home Screen app, publish the folder to an HTTPS host
(e.g., GitHub Pages or another static hosting provider) and open its URL in
Chrome on Android, then choose menu > Add to Home screen / Install.

Booking form sends the enquiry to WhatsApp. Gallery tiles are placeholders;
replace them with your real event images before public launch.
